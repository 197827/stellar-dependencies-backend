# Contributing

Use Node 22+. Create a focused branch, implement your change, run `npm test` and `npm run check`, and describe the behavior change in a pull request. Add regression tests for parser, identity, network and funding-related changes. Keep sample data labeled and avoid live upstream traffic in default tests.

Never commit credentials or real wallet keys. Do not execute scanned package code. Keep “reported metadata” distinct from “verified ownership.” Document support boundaries when adding dependency sources. Contributions use the project's MIT license.
